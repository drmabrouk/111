# Helthedia

**Domain:** `helthedia.org`

## Purpose
Helthedia is a specialized search engine designed exclusively for **scientific, medical, and health-related research**. Its main goal is to provide researchers, doctors, students, and institutions with **reliable, peer-reviewed, and indexed studies** in one centralized platform.

## Core Features
- **Advanced Search:** Search for medical research, journals, and studies with high precision.
- **Filtering:** Sort results by year, journal, author, and open access status.
- **Monochromatic Design:** A clean, professional, and minimalistic interface using a black, white, and grayscale color palette.
- **Fully Responsive:** Optimized for all screen sizes and devices.

## Project Structure
- `client/`: React.js frontend built with Vite.
- `server/`: Python Flask backend API.

## Setup Instructions

### Backend
1. Navigate to the `server` directory: `cd server`
2. Install dependencies: `pip install flask flask-cors`
3. Run the server: `python app.py`

### Frontend
1. Navigate to the `client` directory: `cd client`
2. Install dependencies: `npm install`
3. Run the development server: `npm run dev`

## Testing
- **Backend:** Run `pytest` in the `server` directory.
- **Frontend:** Run `npm test` (using Vitest) in the `client` directory.
